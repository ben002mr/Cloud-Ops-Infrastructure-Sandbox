# CI/CD Management (Azure DevOps)

### Release Management
- **Library Updates:** Managing pipeline variables and date-specific configurations in the Library for scheduled deployments.
- **Frontend/Backend Pipelines:** Overseeing full-stack deployment runs.
- **Deployment Blocks:** Managing weekly approval workflows to ensure safe production releases.
- **Infrastructure Scaling:** Manual scaling of PODs via Rancher/K8s manifests during the transition from inactive to active clusters.
